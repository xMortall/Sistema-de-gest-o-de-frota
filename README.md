#  Sistema de Gestão de Frota

Este projeto consiste num **Sistema de Gestão de Frota** desenvolvido em **Python**, com o objetivo de permitir a administração básica de veículos através de uma aplicação simples com interface gráfica.  
Foi desenvolvido no âmbito académico para consolidar conhecimentos de programação e organização de software.

---

##  Objetivo do Projeto

O objetivo principal deste sistema é permitir:
- O registo de veículos
- A visualização da frota existente
- A gestão simples de informação relacionada com os veículos

A aplicação serve como uma base para futuros sistemas mais completos de gestão de frotas.

---

##  Funcionalidades

✔️ Adicionar veículos à frota  
✔️ Listar veículos registados  
✔️ Interface gráfica intuitiva  
✔️ Estrutura modular em Python  

Funcionalidades futuras possíveis:
- Base de dados (SQLite)
- Gestão de motoristas
- Registo de manutenções
- Relatórios detalhados
